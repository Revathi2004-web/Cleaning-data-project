# Cleaning Data Project

## Project Overview

The objective of this project is to clean and preprocess raw data to improve data quality and prepare it for analysis. The project focuses on handling missing values, removing duplicate records, standardizing data, and performing SQL-based analysis.

---

## Dataset Information

The dataset contains Airbnb/New York listing information, including:

* Listing names
* Host details
* Room types
* Prices
* Reviews
* Availability
* Neighbourhood groups

---

## Tools and Technologies Used

* Python
* Pandas
* NumPy
* Seaborn
* Matplotlib
* MySQL Workbench
* Google Colab

---

## Tasks Performed

### Data Cleaning Using Python

* Loaded dataset using Pandas
* Checked dataset structure and statistics
* Handled missing values
* Removed duplicate records
* Standardized column names
* Detected outliers
* Saved cleaned dataset

### SQL Analysis Using MySQL

Performed various SQL queries such as:

* Viewing complete dataset
* Counting total records
* Finding average price
* Grouping listings by neighbourhood
* Analyzing room types
* Sorting expensive listings
* Filtering data using conditions

---

## Key Insights

* Identified the most common room types
* Analyzed average listing prices
* Observed neighbourhood-wise listing distribution
* Identified highly reviewed and expensive listings
